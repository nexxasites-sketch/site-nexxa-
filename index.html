FAQ

Perguntas rápidas.

O preço do simulador é definitivo?

Não. Ele é uma estimativa para facilitar sua decisão. O projeto final pode ser ajustado conforme escopo, conteúdo e necessidades.

Posso escolher recursos adicionais?

Sim. O simulador recalcula o valor conforme você adiciona ou remove recursos.

Os exemplos são sites separados?

Sim. Cada exemplo possui seu próprio arquivo HTML dentro da pasta “exemplos” e abre como uma página independente.

O site funciona no celular?

Sim. A estrutura foi feita de forma responsiva para telas grandes e smartphones.
